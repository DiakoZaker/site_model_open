راهنمای تنظیم API Key

1

دریافت API Key

از وب‌سایت ارائه‌دهنده (OpenAI، Anthropic، و...) ثبت‌نام کرده و API Key دریافت کنید

2

تنظیم در برنامه

API Key را در تنظیمات برنامه مورد نظر وارد کنید (معمولاً در بخش Settings یا Preferences)

3

تست اتصال

با ارسال یک درخواست ساده، صحت عملکرد API Key را بررسی کنید
